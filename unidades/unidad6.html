Unidad 6 · Responsable: Isaias Llorente

RIP, OSPF y BGP

Introducción conceptual

Analogía cotidiana

El tránsito dentro de una ciudad frente a las autopistas entre países

Dentro de una misma ciudad (Sistema Autónomo), las autoridades locales organizan las calles buscando el trayecto más rápido o corto: en un barrio pequeño basta contar cuadras (RIP), mientras que en una metrópoli se usa un mapa detallado por zonas (OSPF). Pero para cruzar fronteras entre países distintos (proveedores de Internet), los acuerdos no dependen solo de la distancia, sino de tratados y políticas comerciales (BGP).

Concepto técnico

Sistemas Autónomos (AS), IGP y EGP

Internet se estructura como una federación de Sistemas Autónomos (AS), cada uno identificado por un número ASN único y operado bajo una misma administración técnica. Los protocolos de pasarela interior (IGP: RIP, OSPF) optimizan métricas técnicas dentro de un AS, mientras que el protocolo de pasarela exterior (EGP: BGP-4) intercambia alcanzabilidad de prefijos entre distintos AS guiado por políticas.

Sistema Autónomo (Autonomous System · RFC 1930)

Conjunto de redes IP y routers bajo el control técnico de una única organización (un ISP, una universidad o una corporación). Dentro del AS corre un IGP; en los routers frontera (ASBR / Edge) corre BGP para conectarse con otros AS.

RIPv2 · Routing Information Protocol (RFC 2453)

Protocolo interior basado en Bellman-Ford. Mide el costo exclusivamente en número de saltos (hasta 15; 16 = infinito), envía actualizaciones cada 30 segundos mediante UDP puerto 520 (multicast 224.0.0.9 en RIPv2) y soporta máscaras VLSM/CIDR.

OSPF · Open Shortest Path First (RFC 2328 / OSPFv3 RFC 5340)

Protocolo interior de estado de enlace (Dijkstra) encapsulado directamente sobre IP (Protocolo 89). Calcula el costo inversamente proporcional al ancho de banda del enlace, converge rápidamente y escala dividiendo el AS en áreas conectadas al Área 0.

BGP · Border Gateway Protocol (RFC 4271)

El protocolo que sostiene el enrutamiento global de Internet. Opera sobre TCP puerto 179 en dos modalidades: eBGP (entre Sistemas Autónomos distintos) e iBGP (dentro del mismo AS). Selecciona rutas según políticas administrativas y atributos como AS-PATH, LOCAL-PREF y NEXT-HOP.

Comparación técnica: RIPv2, OSPF y BGP-4

Comparación de características técnicas entre RIPv2, OSPF y BGP-4
Característica RIPv2 OSPF BGP-4
Clasificación IGP (Interior Gateway Protocol). IGP (Interior Gateway Protocol). EGP (Exterior Gateway Protocol).
Algoritmo Vector de distancia (Bellman-Ford). Estado de enlace (Dijkstra / SPF). Vector de rutas (Path-Vector).
Métrica o criterio Conteo de saltos (máximo 15). Costo acumulado basado en ancho de banda. Políticas de red y atributos de ruta (LOCAL-PREF, AS-PATH, etc.).
Transporte UDP puerto 520. Directamente sobre IP (Protocolo 89). TCP puerto 179.
Escalabilidad y convergencia Baja; convergencia lenta, apto para redes pequeñas. Alta dentro de un AS gracias a jerarquía por áreas; convergencia rápida. Muy alta (escala a toda la tabla global de Internet); guiado por estabilidad y políticas.
